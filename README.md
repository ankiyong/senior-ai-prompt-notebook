# 시니어 AI 프롬프트 수첩

**사이트:** https://ankiyong.github.io/senior-ai-prompt-notebook/

주제 → 프롬프트 목록 → 상세 → 복사 순서로 사용하는 정적 웹사이트입니다.
현재 주제는 **AI에게 프롬프트 맡기기** 하나입니다. AI가 목적·대상·결과 형식 등을 질문하고, 사용자의 답을 정리해 확인받은 뒤 실행용 프롬프트를 만드는 연습입니다.

정확한 강의 본문이 제공되기 전의 **연습 예시 3개**(요구사항 질문받기, 실행용 프롬프트 만들기, 프롬프트 개선하기)이며 확정 교안이 아닙니다.

## 사용법

주제를 고른 뒤 필요한 예시를 복사해 AI 대화창에 붙여넣으세요. `[대괄호]` 안은 내 상황에 맞게 바꾸고 AI의 질문에 답하세요.
큰 글씨와 검색을 지원하며, 자동 복사가 차단되면 전체 선택 후 직접 복사할 수 있습니다.
글씨 설정만 변경하며 기존 브라우저의 다른 저장 데이터는 삭제하지 않습니다. 이 사이트는 AI 답변을 생성하거나 서버로 입력을 보내지 않습니다.

## 배포

이 저장소는 전용 공개 사이트 저장소입니다. GitHub Pages는 `main` 브랜치의 `/`에서 게시합니다. 별도 빌드, API 키, 외부 라이브러리, 로그인은 없습니다.
업데이트 전 원격 최신 상태를 확인하고, 이 저장소의 사이트 파일만 수정합니다. 다른 저장소의 공개 범위나 사이트는 변경하지 않습니다. 내부 QA 자료와 개발 의존성은 배포하지 않습니다.

## 로컬 실행

```sh
python3 -m http.server 8000
```

`http://localhost:8000/`을 엽니다. 상세 주소는 `#/topic/prompt-partner/requirements` 형태이며 새로고침을 지원합니다. 예전 주소나 알 수 없는 주소는 주제 홈으로 돌아갑니다.
