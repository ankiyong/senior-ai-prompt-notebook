# 시니어 AI 프롬프트 수첩

**사이트:** https://ankiyong.github.io/senior-ai-prompt-notebook/

주제 → 프롬프트 목록 → 상세 → 복사 순서로 사용하는 정적 웹사이트입니다.
현재 주제는 **AI에게 프롬프트 맡기기** 하나입니다.

정확한 강의 본문이 제공되기 전의 **연습 예시 3개**(하고 싶은 일부터 시작하기, 짧게 답하며 결과물 만들기, 부탁할 말을 함께 다듬기)이며 확정 교안이 아닙니다.

## 사용법

예시를 고른 뒤 아무것도 고치지 말고 그대로 복사해 AI 대화창에 붙여넣으세요. 빈칸 입력은 없습니다.
AI가 하고 싶은 일부터 쉬운 말로 한 번에 질문 하나씩 하도록 부탁하는 글입니다. 번호만 답하거나 “모르겠어요”라고 해도 됩니다.
“질문 그만”, “그만 물어봐”, “이제 만들어줘”라고 하면 추가 확인이나 승인 없이 그때까지의 답으로 실제 결과물을 바로 만들도록 지시합니다. “질문 그만라고” 같은 오타도 중단 의도로 처리하도록 적었습니다.
글·계획 등 원하는 초안을 만들며, 부탁할 말 자체가 목적이면 프롬프트를 만듭니다. 부족한 정보는 가정을 밝히거나 미확인으로 표시하고, 개인정보·사실·날짜·금액을 지어내지 않도록 합니다. 의료·법률 판단은 안전한 상담 메모 등의 범위로 제한합니다.

이는 **외부 AI에게 전달하는 지시문**입니다. 이 사이트는 AI 답변을 생성하거나 대화를 자동 진행하거나 서버로 입력을 보내지 않습니다. AI마다 지시를 따르는 정도는 다르며 반드시 따르리라고 보장하지 않습니다.

큰 글씨와 검색을 지원하며, 자동 복사가 차단되면 전체 선택 후 직접 복사할 수 있습니다.
글씨 설정만 변경하며 기존 브라우저의 다른 저장 데이터는 삭제하지 않습니다.

## 배포

이 저장소는 전용 공개 사이트 저장소입니다. GitHub Pages는 `main` 브랜치의 `/`에서 게시합니다. 별도 빌드, API 키, 외부 라이브러리, 로그인은 없습니다.
업데이트 전 원격 최신 상태를 확인하고, 이 저장소의 사이트 파일만 수정합니다. 다른 저장소의 공개 범위나 사이트는 변경하지 않습니다. 내부 QA 자료와 개발 의존성은 배포하지 않습니다.

## 로컬 실행

```sh
python3 -m http.server 8000
```

`http://localhost:8000/`을 엽니다. 상세 주소는 `#/topic/prompt-partner/requirements` 형태이며 새로고침을 지원합니다. 예전 주소나 알 수 없는 주소는 주제 홈으로 돌아갑니다.
