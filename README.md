# 시니어 AI 프롬프트 수첩

**사이트:** https://ankiyong.github.io/senior-ai-prompt-notebook/

주차별 질문을 찾아 복사하는 시니어 AI 수업용 정적 웹사이트입니다. **6주·12개 프롬프트는 수업 샘플**이며 실제 강의 일정이나 확정 교안이 아닙니다.

## 사용법

주차 선택 → 질문 선택 → 프롬프트 복사 → 이용 중인 AI 대화창에 붙여넣기. `[대괄호]` 안은 내 상황에 맞게 바꿉니다. 큰 글씨, 검색, 기기 내 즐겨찾기를 지원합니다. 자동 복사가 차단되면 직접 선택해 복사할 수 있습니다.

개인정보를 입력하지 말고 AI 답변은 공식 자료로 확인하세요. 이 사이트는 AI 답변을 생성하거나 서버에 질문을 저장하지 않습니다. 즐겨찾기와 글씨 설정은 해당 브라우저에 저장됩니다.
